JoinAssist 0.19.1 improves **temporary-table completion** for SSMS 22 x64.

- **Earlier unfinished queries:** an incomplete SELECT in the same flat batch no longer hides subsequent, independently valid `CREATE TABLE #temp`, `DECLARE @rows TABLE` or `SELECT ... INTO #temp` definitions. Recovery respects declaration order, DROP/ALTER and GO scope, and remains conservative around procedures/control flow.
- **Local names without catalog access:** type `FROM #SSN` or `JOIN #SSN` to complete names declared earlier in the same script, even when a metadata connection is unavailable. Automatic JOIN lists still require a typed prefix; use **Mostra suggerimenti** to request an empty-position list explicitly.
- **Columns from SELECT INTO:** qualified `source.*` and explicit joined columns are resolved from visible source metadata. With connection/catalog errors, explicit script-defined columns can still be suggested; unknown star columns are not fabricated.
- **No invented relationships:** SELECT INTO does not copy foreign keys. Completing a temporary JOIN name leaves its ON condition to you; matching column names alone do not establish an FK relationship.

### Update and validation

Use **JoinAssist → Aggiornamenti… → Installa alla prossima chiusura**, or download **JoinAssist-0.19.1.vsix**, verify **SHA256SUMS.txt**, save work and close SSMS before opening the VSIX.

Synthetic tests cover the two-SELECT-INTO/qualified-star pattern, earlier unfinished queries, offline names/columns, alias ambiguity, GO/DDL/control-flow limits, editor insertion and stale scripts. Existing suites and Microsoft's VSIX reader also validate the package. No production SQL, installed extension, user settings or real installer is changed. Live completion against your SSMS/database remains an integration check; this release does not inspect temporary tables already executed in another tab.
