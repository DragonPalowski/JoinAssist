JoinAssist 0.8.0 introduces the **compact menu interface** for SSMS 22 x64.

### What changed

- All commands are grouped under **JoinAssist**. The horizontal strip above query results is removed, while automatic completion and configured shortcuts stay active.
- Query commands target the active supported SQL view; they are disabled for unsupported or closed views. Settings, updates and diagnostics remain available without a query connection.
- Suggestion rows use a compact two-line layout. Object/column names stand out, while column details and FK names distinguish candidates. The complete JOIN preview is shown for the selected relationship.
- Native menu icons and popup/dialog surfaces follow SSMS theme resources. Settings are organized into **Completamento**, **Formato SQL** and **Cache**.
- **Diagnostica…** contains current status and **Copia diagnostica**. Typing inside comments or strings is silent. Saving/cancelling the modeless settings window now closes it correctly.

### Find the menu

SSMS may initially place it under **Extensions → JoinAssist**. To show it on the main menu bar near the other menus, open **Extensions → Customize Menu… → Extensions Menu**, clear **JoinAssist**, then choose **Save and Restart**. SSMS controls exact ordering; the extension does not rewrite your menu-placement preferences.

### Update

From 0.7.0, use **Aggiornamenti… → Scarica aggiornamento** in the existing strip. Save your queries, close every SSMS window and open the verified VSIX. After restarting, use the new JoinAssist menu. Alternatively download **JoinAssist-0.8.0.vsix** and verify it with `SHA256SUMS.txt`.

### Validation

Core/regression, editor insertion, authentication contract, updater, WPF settings and native-menu checks run with synthetic data. Command resources and pkgdef registration are generated with Microsoft VSSDK tools; Microsoft's VSIX reader validates the package. Tests cover margin removal, active-view isolation, closed-view rejection, resource lookup and theme changes. No production database or credentials are used. Native menu placement and behavior on your actual SSMS configuration remain the live integration check.
