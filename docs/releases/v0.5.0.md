JoinAssist 0.5.0 adds **GitHub update checks and verified downloads inside SSMS 22**.

### New

- Click **Aggiornamenti…** in the strip below the query editor to see the installed version, latest ordinary release and release notes.
- Click **Scarica aggiornamento** when a newer version is available. No GitHub account is needed. The VSIX is verified against its expected size and GitHub SHA-256 digest before becoming available.
- Use **Apri cartella**, save your queries, close all SSMS windows and open the downloaded VSIX. The extension never closes SSMS or launches an installer automatically.
- Checks run only on request. Drafts/prereleases and downgrades are excluded. No queries, database details or SQL credentials are sent to GitHub.

### First installation of this version

If you have **0.4.1**, download **JoinAssist-0.5.0.vsix** below and install it manually once, with SSMS closed. The update button is available starting with this version. `SHA256SUMS.txt` supports manual checksum verification.

### Validation

168 core checks, 53 updater checks using synthetic HTTP, editor command forwarding, 34 insertion checks, 27 SSMS/SqlClient contract checks and a WPF update-window smoke check. Microsoft's VSIX reader accepts the package. The real public GitHub API, HTTPS asset redirect, download and SHA-256 path were also exercised without launching an installer.

Experimental community extension; current UI is in Italian. Full in-SSMS installation and interaction still need user verification. See the README for SQL scope and compatibility limits. Saved, verified downloads remain in `%LOCALAPPDATA%/JoinAssist/Updates` until you remove them.
