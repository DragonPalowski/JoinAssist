JoinAssist 0.17.0 adds the **Azioni rapide productivity workspace** and fixes personal-rule completion issues in SSMS 22 x64.

- **Record navigation and FK exploration:** prepare related-record SELECTs, one path or a bounded batch; explore up to five JOIN edges and see metadata-based uniqueness/multiplication notes. Composite keys and untrusted warnings are preserved.
- **Faster query writing:** typed clipboard IN lists, searchable multi-column selection, local/UTC date ranges, duplicate/NULL/grouped/day-count/orphan drafts, dependency and column searches, plus a keep-open schema window.
- **Reusable SQL:** named linked fields with Tab/Shift+Tab navigation and mirrored values; explicit local favorites with categories, descriptions and server/database or global scope. Search actions, favorites and rules from one palette.
- **Refactoring and diagnostics:** full-preview scoped alias rename, rule probes including conflicts/scopes/missing metadata, direct suggestion retry/cache refresh and local preparation timing.
- **Completion fixes:** continued typing no longer retains stale personal replacement spans; Backspace reloads missing alternatives; mid-word shortcuts replace the correct whole token. Explicit retry recreates failed sessions, without an automatic same-prefix error loop.

Open **JoinAssist → Azioni rapide…**. Choose an action, generate a preview, then insert/copy it or explicitly save/open a new SQL file. **Schema affiancabile…** opens the schema action. Optional **Ctrl+Alt+P** is off initially and can be enabled under **Impostazioni → Completamento**. Existing shortcuts and ordinary completion remain available. No generated query is automatically executed.

The schema panel is a separate modeless window, not a docked SSMS pane. FK paths are bounded, cycle/repeated-table paths are excluded, dependency visibility follows SQL permissions, and named template fields are literal SQL rather than escaped parameters. Favorites explicitly save SQL and configured scopes locally in plain text; no automatic history is collected. See the [workflow guide](https://github.com/DragonPalowski/JoinAssist/blob/main/docs/WORKFLOWS.md) for all 15 improvements, limits and examples.

### Update and validation

Use **JoinAssist → Aggiornamenti… → Installa alla prossima chiusura**, or download **JoinAssist-0.17.0.vsix**, verify **SHA256SUMS.txt**, save work and close SSMS before opening the VSIX.

Core, synthetic metadata, favorites concurrency, generated-SQL, alias-scope, rule-regression, WPF dark/light and simulated-editor linked-field/stale-insertion checks run alongside existing suites. Microsoft's VSIX reader validates the package. Tests do not execute production SQL, modify the installed extension/user preferences or launch a real installer. Live SSMS integration remains a manual verification step.
