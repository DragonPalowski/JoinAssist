JoinAssist 0.14.1 fixes unreadable settings in the SSMS dark theme.

- Tab contents and headers now use the host palette, preventing white pages with near-white checkbox text.
- Labels and button captions follow the containing control's text color. The selected tab has a visible indicator, and list selection keeps its own text contrast.
- Theme resource changes update an already-open window. Settings and SQL completion behavior are unchanged.

### Update and validation

Use **JoinAssist → Aggiornamenti… → Installa alla prossima chiusura**, or download **JoinAssist-0.14.1.vsix**, verify **SHA256SUMS.txt**, save queries, close SSMS and open the VSIX.

WPF tests cover all settings pages under dark, light and synthetic high-contrast palettes, including inherited light styles, an incomplete host style dictionary and changes to theme resources while the window is open. Rendered previews are inspected alongside the existing editor/core/authentication tests; Microsoft's VSIX reader validates the package. These tests do not control a live SSMS session, install the extension, save user settings or execute SQL. Real SSMS theme switching remains a manual integration check.
