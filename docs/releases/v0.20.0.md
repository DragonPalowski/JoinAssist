JoinAssist 0.20.0 adds **Da tabella a SELECT** and fixes unwanted suggestions when navigating existing SQL in SSMS 22 x64.

- Enable **Impostazioni → Completamento → Da tabella a SELECT** (off by default). On a new instruction line, type at least two characters of a table/view name, choose the candidate and press **Tab**. `Orders` becomes `SELECT * FROM Orders`. The selected preview shows the exact SQL; the caret goes to its end.
- Optional TOP (blank/0 means no limit) and final semicolon use independent settings. Existing schema, bracket and keyword-case preferences are respected. Existing terminators are preserved. Declared temporary tables/table variables are supported; persistent sources use the active database catalog.
- After another instruction, separate it with **;** or **GO** before the shortcut line. Comments/strings, unfinished SQL, procedures/control flow and ordinary FROM/JOIN/column contexts do not become shortcut targets. Existing keyword and snippet completion keeps priority. Space/Enter do not expand; mouse selection is followed by Tab. Personal SELECT rules are not applied to the generated draft. Nothing is executed.
- Moving the caret through existing SQL closes automatic proposals and cancels pending work. `appo|intments_tb` and equivalent column/JOIN/DML positions stay quiet. Manual **Mostra suggerimenti** remains available, including replacement inside an existing name.
- Updated settings guidance and the built-in searchable guide.

### Update and validation

Use **JoinAssist → Aggiornamenti… → Installa alla prossima chiusura**, or download **JoinAssist-0.20.0.vsix**, verify **SHA256SUMS.txt**, save work and close SSMS before opening the VSIX.

Synthetic core, catalog, settings, editor navigation/insertion and WPF tests run alongside the existing suites. Microsoft's VSIX reader validates the package. Tests never execute production SQL, alter user settings, install the extension or control open SSMS tabs. Real SSMS input-event ordering and completion against your own database remain integration checks.
