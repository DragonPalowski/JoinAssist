JoinAssist 0.19.0 fixes unwanted automatic JOIN proposals while indenting and adds **Disinstalla JoinAssist…** for SSMS 22 x64.

- **JOIN completion respects layout:** empty JOIN/ON positions, whitespace, Tab and newline indentation no longer open automatic FK lists. Start typing a table/reference to request automatic completion. A following JOIN clause suppresses automatic new-JOIN proposals; later WHERE/GROUP/ORDER clauses remain compatible. Ordinary table/column completion is preserved.
- **Tab remains available for indentation:** the controller rechecks the current text/caret before accepting a delayed automatic popup. A manually requested list can still complete an empty JOIN; use **Mostra suggerimenti** (configured shortcut) or **JOIN da foreign key…**. Manual-request state ends after acceptance.
- **JoinAssist → Disinstalla JoinAssist…** identifies the current SSMS 22 instance and opens its Microsoft VSIX removal procedure for JoinAssist only. It shows per-user/machine-wide scope, retains installer prompts, checks pending updates and refuses unidentified/changed targets. It does not close SSMS, delete folders or remove saved rules/favorites. Save work and complete the installer yourself; its final outcome is not inferred by the plugin.
- Updated offline JOIN instructions and added uninstall guidance (30 topics in the built-in guide). See [removal behavior and limits](https://github.com/DragonPalowski/JoinAssist/blob/main/docs/UNINSTALL.md).

### Update and validation

Use **JoinAssist → Aggiornamenti… → Installa alla prossima chiusura**, or download **JoinAssist-0.19.0.vsix**, verify **SHA256SUMS.txt**, save work and close SSMS before opening the VSIX.

Layout/neighboring-clause tests, simulated editor Tab/manual-request checks, synthetic uninstall target/argument/race tests and dark/light UI checks run alongside existing suites. Microsoft's VSIX reader validates the package. No production SQL, installed plugin, user settings or real installer is changed by tests. Live SSMS indentation and actual VSIX uninstallation remain manual integration checks.
