JoinAssist 0.22.2 restores **Tab for indentation** while keeping completion available as soon as you type a prefix.

- `JOIN` + Tab, `JOIN ` + Tab and blank/indented positions are left to SSMS. Automatic JOIN proposals start with a name, for example `JOIN C`.
- The same rule applies to tables, columns, UPDATE/INSERT and optional EXEC completion. After `FROM `, `alias.`, `INSERT INTO Orders ` or an empty parameter position, type at least one character of the name to open suggestions. Full INSERT drafts and empty-prefix lists remain available through **JoinAssist → Mostra suggerimenti**.
- Delayed results and lists left open before whitespace cannot steal Tab. Existing typed LIKE/IN templates and linked-field navigation remain available. Explicit personal rules configured for Space still work, without mistaking native Tab converted to spaces for an intentional Space press.
- Keyword/filter and optional table-to-SELECT suggestions now also accept a one-character prefix. Moving the cursor into existing words still does not request automatic completion.

### Update and validation

Use **JoinAssist → Aggiornamenti…**, or download **JoinAssist-0.22.2.vsix**, verify **SHA256SUMS.txt**, save work and close SSMS before installing.

Regression checks cover empty contexts, one-letter prefixes, stale-list acceptance, asynchronous Space rules and forwarding Tab to the native editor. Existing completion, temporary-table, execution-review and package-validation checks run alongside them. No production SQL, user preferences or installed extension is modified by these tests; installed-SSMS indentation remains an integration check.
