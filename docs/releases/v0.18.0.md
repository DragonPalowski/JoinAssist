JoinAssist 0.18.0 adds an **offline, searchable user guide** for SSMS 22 x64.

- **JoinAssist → Guida…** works even without a query or database connection. Its 29 topics explain completion and the less obvious features, with practical steps, fictional examples, limits and troubleshooting.
- Search the full content with **Ctrl+F**, ignoring case/accents. Related-topic links and explicit buttons open the relevant settings page or quick action. **Copia esempio** copies demonstration SQL only; nothing is inserted or executed.
- **Guida / F1** in plugin dialogs opens contextual help for settings, quick actions, SELECT rules, shortcuts, DELETE plans, schema, JOIN, diagnostics and updates. SSMS editor F1 remains unchanged.
- Host-themed, resizable and scrollable guide, with no network or metadata requirement. Tool-opening buttons are disabled while reading help from a modal editor, preserving unsaved drafts. Diagnostics buttons now wrap for smaller windows.

Existing completion, rules and query-generation behavior are retained. Opening a tool is explicit; opening Updates uses the existing on-request GitHub check. Guide searches are not stored. See the [guide reference](https://github.com/DragonPalowski/JoinAssist/blob/main/docs/HELP.md).

### Update and validation

Use **JoinAssist → Aggiornamenti… → Installa alla prossima chiusura**, or download **JoinAssist-0.18.0.vsix**, verify **SHA256SUMS.txt**, save work and close SSMS before opening the VSIX.

Offline help coverage/search/link/context tests and dark/light/compact-window rendering run alongside existing core, simulated-editor, authentication and packaging suites. Microsoft's VSIX reader validates the package. Automated checks do not execute production SQL, read the clipboard, save user preferences or launch a real installer. Live SSMS integration remains a manual verification step.
