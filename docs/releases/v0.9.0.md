JoinAssist 0.9.0 adds productivity tools and context-aware completion for **SSMS 22 x64**.

### What changed

- Column ordering uses local scope and ON/comparison context within text-match bands. Exact names remain first; table/view proximity ordering is preserved.
- Complete simple partially written ON conditions, including `o.Cust` and `o.CustomerId = c.I`, using real foreign keys. Keep the typed side, existing aliases, all composite-key pairs and the following query clauses. Ordinary column suggestions remain available.
- **Espandi colonne (*)…** lets you choose and preview explicit SELECT columns before replacing a star. Source order and existing aliases are preserved; Ctrl+Z undoes the edit. COUNT(*) and unresolved/ambiguous sources are rejected.
- **Informazioni tabella / colonna…** shows column types/properties and real mapped FK relationships for tables, aliases, columns and resolvable CTE/derived sources. Metadata only; the edited SQL is never executed.
- CTE/derived expression outputs retain types that can be inferred safely from CAST/CONVERT/TRY variants, compatible CASE/COALESCE branches, literals and selected built-ins. Unknown coercions stay unknown, with no invented FK lineage.
- Reuse unchanged lexical prefixes, independent semicolon-separated SELECTs and GO batches. Procedural/stateful or uncertain boundaries keep a full-analysis fallback. Memory caches are bounded.
- Apply JoinAssist's main-menu default once in recognized SSMS Customize Menu settings, preserving other extensions and later user choices. The placement can require the next normal restart. No forced restart.

### Use the new tools

Open **JoinAssist**. Place the cursor on a SELECT `*` or `alias.*`, then choose **Espandi colonne (*)…**. Put it on a table, alias or qualified column for **Informazioni tabella / colonna…**. These commands use the active query's connection and metadata visibility.

If the menu is initially grouped under Extensions, restart SSMS normally after saving your work. The fallback is **Extensions → Customize Menu… → Extensions Menu**, clear **JoinAssist**, then **Save and Restart**. SSMS controls exact ordering.

### Update and validation

From 0.8.0 use **JoinAssist → Aggiornamenti… → Scarica aggiornamento**, or download **JoinAssist-0.9.0.vsix** and check `SHA256SUMS.txt`. Save your queries and close all SSMS windows before opening the verified VSIX. No automatic installation or shutdown is performed.

Synthetic core, incremental lexer/parser, metadata, editor insertion, menu-default, WPF, authentication-contract and updater tests pass. Microsoft VSSDK tools compile the menu/resources and generate package registration; Microsoft's VSIX reader validates the package. Production databases, credentials and user query tabs are not used by the tests. Installed SSMS behavior and native menu placement remain a live integration check after updating.
