JoinAssist provides free table, column and foreign-key JOIN completion for **SSMS 22 x64**.

This is the first public release and remains experimental. The current interface is in Italian.

### Included

- Automatic JOIN and ON suggestions based on actual foreign keys.
- Table/view and column completion, with Tab/Enter acceptance.
- Prefix ranking that prefers closer names, such as `customers_tb` ahead of `customerActivityHistory_vw` for `custo`.
- Compact generated SQL and support for existing aliases.
- CTE, derived-query and view support where direct column lineage can be resolved safely.

### Install

Download **JoinAssist-0.4.1.vsix** below, save your queries, close all SSMS windows and open the VSIX. Select SSMS 22 in Microsoft's installer, then reopen SSMS and connect a query tab. `SHA256SUMS.txt` contains the package checksum.

### Validation and limits

Validated with 168 core checks, editor command forwarding and 34 insertion checks, 27 SSMS/SqlClient contract checks using synthetic tokens, and Microsoft's VSIX package reader. The full local build used SSMS 22.11 tooling. The earlier JOIN/connection path was verified interactively; the expanded completion features still need wider live testing across environments. Tests do not contact a real SQL Server or guarantee all authentication configurations.

See the README for unsupported SQL constructs and troubleshooting. Updates currently require downloading a newer VSIX; the in-SSMS GitHub update button is not implemented.
