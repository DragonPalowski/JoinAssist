JoinAssist 0.16.0 adds **personal completion rules** for SSMS 22 x64.

- **New Regole settings tab:** create, preview, edit, duplicate, enable/disable, delete, import and export local rules. Draft changes apply only after saving settings; no rules are active initially.
- **SELECT defaults per table/view:** add TOP and first-column/named-column ordering when absent. Accept the rule for `logs.logs_tb` to prepare `SELECT TOP 100 * FROM logs.logs_tb ORDER BY 1 DESC`. Existing TOP, ORDER BY, WHERE, comments and later statements are preserved; complex SELECT forms are excluded.
- **Literal SQL shortcuts:** expand a configured word with Tab, with an optional `$cursor$` marker. Global shortcuts work offline; optional server/database scopes prioritize specific rules while keeping ties separate.
- **Optional Space action:** opt in per rule to apply after its complete exact name and a space, with automatic completion on and one personal choice. Moving the caret, changing the query/connection or conflicting alternatives blocks the pending action.
- **Integrated previews and themes:** personal proposals show their full SQL and rule name. One editor edit supports Ctrl+Z. Dialogs follow the host theme, including fallback dropdowns when a host style is unavailable.

Open **JoinAssist → Impostazioni… → Regole → Nuova SELECT** or **Nuova scorciatoia**. For the logs example set schema `logs`, table `logs_tb`, TOP `100`, order **Prima colonna** and **DESC**, then **Usa regola → Salva**. Enable **Applica anche con Spazio** only if you want automatic expansion. Generated keyword case follows **Formato SQL**.

Configured SQL and scope names are saved locally in preferences and included in explicit JSON exports. Imports arrive disabled with automatic Space off. Rules never execute SQL or read business rows. See the [complete guide](https://github.com/DragonPalowski/JoinAssist/blob/main/docs/PERSONAL-RULES.md) for scopes, contexts and limits.

### Update and validation

Use **JoinAssist → Aggiornamenti… → Installa alla prossima chiusura**, or download **JoinAssist-0.16.0.vsix**, verify **SHA256SUMS.txt**, save queries, close SSMS and open the VSIX.

Synthetic tests cover transformations/spans, scopes/case resolution, preservation/exclusions, snippets/caret position, offline keywords, draft persistence/import, automatic Space/conflicts/stale refusal, one-edit insertion and dark/light UI previews. Existing core, editor, authentication and packaging suites run before publication; Microsoft's VSIX reader validates the package. No production database, edited SQL, user settings or real installer is executed by tests. Live SSMS behavior remains a manual integration check.
