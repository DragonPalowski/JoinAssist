JoinAssist 0.7.0 brings eight improvements to completion in **SSMS 22 x64**.

### Added and improved

1. **Large-query responsiveness:** typing analysis runs in the background and coalesces pending snapshots; bounded analysis caches reuse work. Qualified column requests load only the requested source.
2. **Metadata cache:** catalog names, columns and foreign keys stay in memory for two minutes by default, isolated by connection/session/server/database. **Aggiorna metadati** invalidates the current scope. Expiry is configurable.
3. **SQL context recovery:** incomplete correlated subqueries, APPLY, CTE chains and WITH definitions in later UNION branches retain their legitimate sources. Alias shadowing and ordinary derived-table boundaries remain enforced.
4. **Diagnostics:** clearer status codes explain absent suggestions; **Copia diagnostica** copies versions and a diagnostic code, without raw messages, query text or connection details.
5. **Saved settings:** **Impostazioni…** controls automatic completion, delay, cache lifetime, Tab/Enter acceptance, manual shortcut, SQL style and two-hop paths. **Ctrl+Alt+Space** invokes completion manually; Tab always accepts. Compact SQL remains the default.
6. **INSERT / UPDATE:** complete column names in ordinary INSERT lists and UPDATE SET assignments, including UPDATE alias FROM and script-defined local tables. Already specified, known identity, computed and rowversion columns are excluded.
7. **Two-hop JOIN paths:** labelled proposals can insert a path through one intermediate physical table, with a complete preview and composite FK conditions. Disabled edges and repeated table IDs are excluded; untrusted constraints retain a warning. Paths are bounded and optional.
8. **Column details:** type/length, precision/scale, nullability, PK/FK and identity/computed metadata appear when available. Derived output columns do not claim inherited constraints.

Preferences alone are saved in `%LOCALAPPDATA%/JoinAssist/preferences.json`. Query analysis and metadata caches remain in memory; there is no new external service, credential storage, telemetry or user-SQL execution. Complex DML forms, TOP and CTE DML targets are not fully resolved. Metadata does not certify that a view is writable.

### Update

Use **Aggiornamenti… → Scarica aggiornamento** in SSMS, then **Apri cartella**. Save your queries, close all SSMS windows and open the verified VSIX. Alternatively download **JoinAssist-0.7.0.vsix** below and use `SHA256SUMS.txt` to verify it. GitHub's source ZIP is not the installer.

### Validation

Synthetic core/regression coverage includes cache isolation, expiry, concurrency, in-flight refresh, settings persistence in temporary test files, incomplete nested SQL, DML names, complete composite FK paths, metadata details and focused loading. Editor tests exercise INSERT/UPDATE/two-hop insertion and suffix preservation; WPF tests cover the settings window and shortcut configuration. Existing updater, SSMS/SqlClient contract and Microsoft VSIX-reader checks also run. No production query, database or credentials were used. A live query tab with your own SSMS/database configuration remains the final integration check.
