JoinAssist 0.6.1 fixes **missing column suggestions in larger/unfinished scripts** and **JOIN completion before existing clauses**.

### Fixed

- Earlier unfinished SELECT, WHERE or JOIN statements no longer hide ordinary table/alias columns in the current SELECT. Recovery also handles incomplete SELECT lists and unrelated filter/ON expressions, while keeping resolvable CTEs.
- Column suggestions work after SELECT DISTINCT/TOP, in CASE branches, after LIKE/BETWEEN and comparison operators.
- JOIN and ON candidates remain available before existing WHERE, GROUP BY, HAVING and ORDER BY clauses, including unfinished tails. Insertion preserves the suffix and comments exactly.

Recovery changes only an analysis copy. It does not execute SQL, alter the original text for parsing or infer columns from unknown source definitions. Existing scope/connection checks still apply.

### Update

In SSMS, use **Aggiornamenti… → Scarica aggiornamento**. After verification, choose **Apri cartella**, save your queries, close all SSMS windows and open the VSIX. Manual download: **JoinAssist-0.6.1.vsix** below, with `SHA256SUMS.txt` for verification.
