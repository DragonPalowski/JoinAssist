JoinAssist 0.12.1 fixes missing suggestions in unfinished SELECT lists for SSMS 22 x64.

Typing a table prefix before an existing qualified column could hide the query's table/alias suggestions when the separating comma had not yet been entered. The parser retained a partial SELECT without its FROM sources. JoinAssist now recovers those sources from an analysis-only copy, including JOINs, aliases, CTEs and derived tables.

For example, typing `Ord` in the following position now offers the joined `Orders` reference:

```sql
SELECT
    Ord -- caret immediately after Ord
    Customers.Name
FROM Orders
JOIN Customers ON Orders.CustomerId = Customers.Id
```

Accept the name, type a dot and choose a column. Add the separating comma when finishing the SELECT list. Completion replaces only the typed name and preserves the following query text; it does not execute SQL.

### Update and validation

Use **JoinAssist → Aggiornamenti… → Installa alla prossima chiusura**, or download **JoinAssist-0.12.1.vsix**, verify **SHA256SUMS.txt**, save your queries, close SSMS and open the VSIX.

Synthetic end-to-end regressions cover the reported query structure with fictitious names, multiple joins/statements, aliases, CTEs, derived sources, exact text preservation and subsequent column completion. Core tests, the full editor/UI regression suite and Microsoft's VSIX package reader are checked before publication. Live typing in the user's SSMS/database session has not been tested by this automated suite.
