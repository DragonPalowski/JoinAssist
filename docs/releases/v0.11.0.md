JoinAssist 0.11.0 adds **INSERT structure proposals** for SSMS 22 x64.

### Use it

Type `INSERT INTO TableName `, including the final space. Choose **Prepara INSERT** and press **Tab**. JoinAssist inserts a multiline column list in table order plus matching `VALUES (@column, …)` placeholders, then moves the caret to the first value. The parameters must be replaced or declared by you; no data is fetched or written.

Inside an empty INSERT column-list position, **Inserisci colonne mancanti** adds names not already present before or after the cursor. It preserves existing parentheses, VALUES and later statements. Ordinary single-column proposals remain available; typing a column prefix filters those names as usual.

- Exclude identity, computed, rowversion and generated-always columns.
- Include default columns initially; disable **Includi colonne con valore predefinito nella struttura INSERT** in **Impostazioni → Completamento** to omit them from bulk proposals.
- Preserve indentation, LF/CRLF line endings, keyword casing and necessary identifier delimiters. Generate distinct valid placeholder names for unusual column names.
- Require known writeability and a real table, or an explicitly declared local table/variable. Do not generate structures for views, synonyms, CTE targets or unknown metadata; never borrow a same-named physical table for a CTE.
- Do not overwrite an existing INSERT SELECT, VALUES or OUTPUT clause. A column-list fill changes only names; it does not invent or extend existing values. Review column/value alignment after filling a partial list.

### Update

Open **JoinAssist → Aggiornamenti… → Installa alla prossima chiusura** from 0.10.0 or newer. Otherwise download **JoinAssist-0.11.0.vsix**, verify **SHA256SUMS.txt**, save your work, close all SSMS windows and open the VSIX. Microsoft installer confirmations remain user actions.

### Validation

Synthetic tests cover catalog/local metadata, ordering and exclusions, defaults preference persistence, special-name placeholders, parsed INSERT syntax, existing column/value preservation, CTE shadowing, editor insertion and first-value caret placement. Core/editor/menu/authentication/updater checks and Microsoft's VSIX reader are run before publication. No production database, edited INSERT or real installer is executed. Interactive validation in a live SSMS query tab remains an integration check after updating.
