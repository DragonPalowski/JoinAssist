JoinAssist 0.13.0 improves table and column suggestions in SSMS 22 x64.

- Find real names despite small typing errors, swapped letters or an unfinished misspelled prefix: `patietns` → `patients_tb`, `prescir` → `prescriptions_tb`.
- Recognize word starts/abbreviations in camelCase and snake_case and compare direct prefixes without the length of `_tb`/`_vw`. Correct names and prefixes stay ahead of corrections.
- Prefer visible query sources and actual FK JOINs within each text-match group. Search a reference by its original table/CTE name or existing alias; accepting it inserts the reference already used in the query. Homonymous columns show their original table/schema and receive qualification when needed.
- Highlight matched characters, label possible corrections and preserve an explicit selection as you continue typing while it remains valid. Tab inserts the visible selected candidate; nothing is silently corrected or executed.
- Learn accepted choices locally per server/database as a bounded tie-breaker. Save only hashed identifiers/counts/timestamps; no SQL or credentials. Disable or reset memory in the new **Impostazioni → Ricerca** page.
- Choose **Precisa**, **Equilibrata** (default) or **Tollerante**. Balanced mode offers typo corrections from four characters when no literal name/prefix exists; tolerant mode also keeps them below direct results and starts at three. Matching/ranking is cached, cancellable and off the UI thread.

Read [search behavior and limits](https://github.com/DragonPalowski/JoinAssist/blob/v0.13.0/docs/SMART-COMPLETION.md). Schemas and qualifier bindings remain literal; metadata visibility and SQL context still determine available candidates. Learning is best effort and local, not an exact synchronized usage log.

### Update and validation

Use **JoinAssist → Aggiornamenti… → Installa alla prossima chiusura**, or download **JoinAssist-0.13.0.vsix**, verify **SHA256SUMS.txt**, save queries, close SSMS and open the VSIX.

Synthetic matching/distance/context/history/settings tests, rendered WPF highlights, editor selection/Tab insertion and stale-snapshot checks are run with existing regressions. Core tests run on GitHub and Microsoft's VSIX reader validates the package before publication. No edited SQL, production database or installer is executed by these tests. Live typing in every SSMS/theme/authentication combination has not been verified by this automated suite.
