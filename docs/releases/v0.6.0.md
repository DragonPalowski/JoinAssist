JoinAssist 0.6.0 improves **name search, JOIN relationship display and local-table completion** for SSMS 22 x64.

### New

- **Flexible table and column search:** `itemdet` finds `OrderItemDetails` and `order_item_details_tb`. Exact names and prefixes remain first, followed by internal fragments, separator-insensitive matches and compact ordered abbreviations. Explicit schema filters stay exact.
- **Clearer JOIN choices:** each row shows the mapped ON columns and actual FK name. Multiple relationships to the same table, such as creator/modifier user IDs, are distinguishable without selecting each row. Composite conditions, aliases and FK warnings remain visible; inserted SQL is unchanged.
- **Local tables:** name/column completion for earlier top-level `CREATE TABLE #temp`, `DECLARE @table TABLE` and resolvable `SELECT ... INTO #temp`, including aliases, star expansion and projection through CTEs/derived queries.

### Local-table limits

This analyzes script text without executing SQL or reading session temporary tables. SELECT INTO retains the source shape at its position in the script and never inherits FK suggestions. DROP/recreate updates the definition; ALTER, conditional DDL and dynamic/procedure execution invalidate uncertain assumptions. `@table` variables do not cross GO. Global `##temp`, procedure/control-flow declarations, user-defined table types and definitions in other tabs are excluded. See the README for details and examples.

### Install or update

From 0.5.0, click **Aggiornamenti… → Scarica aggiornamento** in SSMS. After checksum verification, use **Apri cartella**, save your queries, close all SSMS windows and open the VSIX. Alternatively download **JoinAssist-0.6.0.vsix** below. `SHA256SUMS.txt` is included for manual verification.
